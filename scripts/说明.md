# 原神 4.0 私服（Grasscutter）使用说明

整套东西都在 `C:\XH_YS`，教程来源：<https://github.com/xb1520/Grasscutter_build>。
打开 `C:\XH_YS` 只会看到四个文件夹：**`游戏`**（客户端本体）、**`配置`**（服务端 / 数据库 / 工具 / 教程源码）、**`脚本`**（bat 入口、底层 ps1/cmd、本说明）、**`教程`**（换电脑或给朋友用时的部署/打包指南 + 一键部署脚本）。
当前状态：**双击一个脚本就能从零进游戏**（已实测：重启电脑后冷启动 → 自动开服 → 自动点启动器 → 进游戏世界，UID 10001，延迟 6~8ms）。

## 一、怎么玩（就一件事：双击）

1. 双击 **`C:\XH_YS\脚本\开始游戏.bat`**
   它自己按顺序做完 6 件事，不用你点任何按钮：
   1. 关掉系统代理（防止上次残留的 8365 代理捣乱）
   2. 起 MongoDB（已在跑就跳过）
   3. 杀掉残留 java，重新起 Grasscutter 服务端（另开一个黑窗口）
   4. 轮询 `http://127.0.0.1:443/query_region_list`，真等到服务端能应答才继续（最长 120 秒）
   5. 校验客户端补丁 `version.dll` / `PublicKey.txt`，缺了或对不上就自动从 `配置\工具\patch_master` 装回去
   6. 启动启动器，用 Windows UIAutomation 找到黄色【启动】按钮并自动点击（窗口先置顶，避免被别的窗口挡住）
2. 之后游戏自己起来：
   - **多数情况**：客户端记着上次登录，会直接到「点击进入」，点一下即进服，UID 10001。
   - **弹出 HOYOVERSE 登录框**（第一次登录 / 清过缓存）：账号 `test`、密码 `123456`，自己随便填也行，`account.autoCreate = true` 会自动建号。
3. 玩完双击 **`C:\XH_YS\脚本\关闭游戏.bat`**：关游戏 → 关启动器 → 复位系统代理 → 关服务端 → 关数据库（`mongod --shutdown` 正常落盘）。

> **启动器那个窗口别关。** 它开的 8365 代理负责把 HOYOVERSE 登录请求转给本地服务端，关掉它登录就会失败；关服请用 `关闭游戏.bat`，它会连代理一起复位。

> **换电脑 / 打包发给朋友**：整套文件夹复制（或压缩）到新机器后，先双击 `教程\一键部署.bat` —— 它会按新机器的实际情况找/装 Java 17、修客户端补丁、重写启动器配置，最后问你要不要直接开服。以后照旧双击 `脚本\开始游戏.bat`。给朋友的具体步骤见 `教程\部署教程.md`，你自己打包时注意什么见 `教程\打包与分享说明.md`。

## 四、账号与指令

`config.json` 里 `account.autoCreate = true`：登录时自动建号，用户名随便填。默认账号没有管理权限，`account.defaultPermissions` 已设成 `["*"]`（下次重启服务端后新账号全权限），**当前 UID 10001 已经单独授了 `*`，游戏里直接用不报“没权限”**。

### 游戏内（聊天框）

按 **Enter** 打开左下角输入框，命令**以 `/` 开头**，回车发送：

```
/give 201 99999        给自己 99999 个原石（201 是原石 ID）
/give 10001 201 5000   给别人（@UID 写法也行：/give @10001 201 5000）
/prop 1000 3000        改属性
/permission list       看自己有哪些权限
/kick 10002            踢人
/help                  全部指令
```

### 服务端黑窗口（不用权限，建议改数值用这个）

标题是 `Grasscutter Server`、里面显示过 `加载完成！输入 "help" 查看命令列表` 的那个窗口，**不带 `/`** 直接敲：

```
help                       查看全部指令
account create 名字         手动建号
account list               列出账号
give 10001 201 99999       给 UID 10001 发 99999 个原石
prop 10001 1000            设置某属性
kick 10001                 踢下线
```

> 如果窗口里已经显示 `Server stopped. Press any key to close this window.`，说明这是**上一次运行留下的死窗口**，在里面敲什么都会报 `'/give' 不是内部或外部命令`。真正在跑的服务端是最新开的那个窗口（或者重跑 `开始游戏.bat`）。
> 服务端的输入是通过 Windows Terminal（ConPTY）转发的，别的程序没法直接往里灌输入，所以老老实实手敲最快。

**命令里为什么非要写 `@10001`**：服务端和执行工具都不存在“我自己”这个概念，必须明确指出目标是哪个玩家；只有在**游戏内聊天框**里敲，发送者就是自己，才可以省略 `@UID`。
- 游戏内：`/setstats cdr 100%`、`/give 201 1000`
- 工具 / 黑窗口：`setstats @10001 cdr 100%`、`give @10001 201 1000`

另外 `give`/`setstats` 这类命令**要求目标玩家在线**，人不在世界里会回「此命令需要在线目标 UID，但当前目标离线」。

可用属性名（`stat` 的 `<stat>` 参数）：`cdr`(冷却缩减) `cr`(暴击率) `cdmg`(暴击伤害) `atk`/`atk%` `hp`/`hp%` `def`/`def%` `em`(精通) `er`(充能) `dmg`(伤害加成) `heali`(治疗加成) `shield`(护盾强效)，值可以写 `100%` 或 `1.0`。

### 图形化（推荐：不用开游戏、不用碰黑窗口）

**双击 `C:\XH_YS\脚本\指令工具.bat`**（在 `脚本` 文件夹里，不在根目录了）就行。它就是 GitHub 上 `jie65535/GcTools`（GrasscutterTools），最新版正好是 v1.13.0（2023-10-21），本机 `配置\工具\GcTools-v1.13.0.exe` 就是这一版，不用再下载。

已经配好，不用再填任何东西：
- 服务器地址：`http://127.0.0.1:443`（已预置）
- token：已预置成插件配置里的 `consoleToken`
- 默认 UID：10001（已预置）

用法：
1. **底部命令框**：输入不带 `/` 的命令 → 按 **F5**（或点「执行」），结果直接回显在下方框里。命令里 UID 前要带 `@`，例如 `give @10001 201 1000`、`prop @10001 1000 3000`。
2. **左侧分类页面**（物品 / 角色 / 武器 / 生成 / 属性 / 场景 / 天气 / 邮件 / 任务…）：点开点选，工具自动拼好命令再执行，最省事。
3. 换服务器或换 token：左侧「设置」里改，改完保存。

小提示：命令框带自动补全，手打「give」再按空格有时会把空格吃掉、变成 `give10001`（服务端回「未知命令」）。**整条命令 Ctrl+V 粘贴进去最稳**，按 F5 前瞄一眼框里内容对不对。

报错对照：`未知命令 xxx` = 命令拼错（多半是空格丢了）；`403 forbidden` = token 不对；连不上/超时 = 服务端没启动（先跑 `开始游戏.bat`）。

## 五、关键配置（已调好，改之前先看这里）

### 服务端 `C:\XH_YS\配置\服务端\config.json`

- `server.http.bindPort = 443`、`accessPort = 0`（0 表示回落 bindPort）
- `server.http.encryption.useEncryption = false` —— 故意关 HTTPS，服务端走纯 HTTP
- `server.http.encryption.useInRouting = false` —— **关键**：控制 dispatch 下发给客户端的地址是 `http://` 还是 `https://`。设成 true 会拼出 `https://127.0.0.1:443/...`，客户端拿 https 连明文端口必挂，表现为 4206
- `server.game.bindPort = 22102`（**UDP**，用 TCP 测一定不通，别误判）
- `databaseInfo` → `mongodb://localhost:27017`，库 `grasscutter`
- `account.autoCreate = true`、`server.dispatch.regions = []`（空数组正常，HYBRID 模式会自建 `os_usa`）

### 启动器 `C:\Users\56958\AppData\Roaming\cultivation\configuration.json`

（`开始游戏.bat` 每次自动校准这几项）

- `toggle_grasscutter = true` —— 这个开关对应界面上的「以 Grasscutter 模式连接」，**必须 true**，否则启动器不开 8365 代理、不套客户端补丁
- `https_enabled = false` —— 必须 false（勾了就是 502 服务器繁忙）
- `patch_rsa = true`、`use_internal_proxy = true`
- `game_install_path = C:\XH_YS\游戏\GenshinImpact.exe` —— **必须是 exe 全路径**，填目录会变成“打开资源管理器”
- `grasscutter_path`、`java_path` 分别为 jar 与 java 全路径
- `last_ip = 127.0.0.1`、`last_port = 443`

> 改这个 json 之前先 `Stop-Process Cultivation`：启动器退出时会把内存里的配置回写，先改会被覆盖。

## 六、它是怎么连上的（原理，排障时有用）

1. `开始游戏.bat` 把 Grasscutter 起在本地 **443/TCP**（明文 HTTP），负责 `query_region_list`、`query_cur_region`、登录 token、以及 **22102/UDP** 的游戏世界。
2. 启动器被点【启动】后：开本地代理 **8365**，把系统代理写成 `http=127.0.0.1:8365;https=127.0.0.1:8365` 且 `ProxyEnable=1`；用 hudsucker 劫持 `*.hoyoverse.com` / `*.mihoyo.com` / `*.yuanshen.com` 白名单域名，把路径改写后转发到 `http://localhost:443`。
   **注意：`127.0.0.1` 不在白名单里**，所以“让 dispatch 指向 127.0.0.1 以绕开代理”这条路走不通。
3. `version.dll` 是客户端侧的 **RSA 公钥补丁**（87040B，替换客户端内置的官方公钥 + 读 `PublicKey.txt`）。客户端拿它验服务端签名，验不过就会在 dispatch 阶段直接失败。
4. 启动器退出（或被强杀）会执行 unpatch，**把 `version.dll` 直接删掉**；所以补丁是“一次性”的，脚本第 5 步每次都会检查并装回。

## 七、常见问题（都踩过，按这个查）

| 现象 | 原因 / 处理 |
| --- | --- |
| 弹「网络错误 4206」提示「准备下载资源」 | ①dispatch 下发的地址是 https 而服务端是明文 → 检查 `useInRouting = false`；②客户端根目录 **缺 `version.dll`**（最常见，尤其重启后）→ 从 `配置\工具\patch_master` 拷回去，或直接重跑 `开始游戏.bat`；③服务端没起来/被重启 |
| 弹「4214 / 4210 / 4208」 | 同上，本质是客户端 RSA 验签失败（`DecryptRegionDispatch Decrypt VerifyHash Fail`），补 `version.dll` + `PublicKey.txt` |
| 登录「服务器繁忙 / 502」 | 启动器勾了「使用 HTTPS」，或启动器没开（没有 8365 代理，登录页的输入框都点不动） |
| 登录框里打字没反应 | 没有 8365 代理，SDK 登录页是空壳。确认启动器在跑、`ProxyEnable=1`、8365 在监听 |
| 点了【启动】只弹资源管理器 | `game_install_path` 填成了目录，必须是 `C:\XH_YS\游戏\GenshinImpact.exe` |
| 启动器闪退（退出码 101） | 没带 `--no-admin` |
| 玩着玩着「网络问题」 | 服务端被关/崩了；看「Grasscutter Server」窗口，重跑 `开始游戏.bat` |
| 关掉启动器后浏览器上不了网 | 系统代理还指着已关闭的 8365：跑 `关闭游戏.bat`，或设置 → 网络和 Internet → 代理 → 关掉「使用代理服务器」 |
| 443 被占用 | `Get-NetTCPConnection -State Listen -LocalPort 443` 看占用进程，常见是残留 java；`关闭游戏.bat` 可清 |
| 脚本第 6 步没自动点中【启动】 | 屏幕上其它窗口太乱。脚本已先把启动器置顶，仍失败就手动点一下黄色【启动】，其余流程照旧 |
| 服务端窗口中文乱码 | 控制台代码页问题，不影响运行；日志文件本身是 UTF-8 |

**手动复位系统代理**：设置 → 网络和 Internet → 代理 → 关掉「使用代理服务器」。
**证书**：Cultivation 在 `Cert:\CurrentUser\Root` 装了一张 `O=Grasscutters, CN=Cultivation` 的根证书；不想要可在 `certmgr.msc` → 受信任的根证书颁发机构 删除。

编辑 `配置\服务端\data\Banners.json`，一条记录一个池子：

- `bannerType`：`BEGINNER` / `STANDARD` / `CHARACTER` / `CHARACTER2` / `WEAPON`（它决定抽一次花哪种石头、保底权重）
- `rateUpItems5`：五星 UP，角色填角色 ID（例：`10000070` 纳西妲、`10000052` 雷电将军），武器填武器 ID（例：`15501`）
- `rateUpItems4`：四星 UP，同上（例：`10000014` 芭芭拉、`10000031` 菲谢尔）
- `prefabPath`：祈愿页顶部的立绘资源名；`titlePath` 是标题文本键
- `beginTime` / `endTime`：Unix 秒，不想算就保持现在的大范围

`watchGachaConfig: true` 已开，**改完保存就会自动重载，不用重启服务端**。

如果进游戏发现祈愿页立绘是空白、或者整页打不开，把 `prefabPath` 换成别的编号试（例如 `GachaShowPanel_A092` → `A096` / `A086` / `A026`），保存后重新打开祈愿页即可，不影响抽卡本身。

### 想改商城

- 商品内容来自 `resources\ExcelBinOutput\ShopGoodsExcelConfigData.json`，要动就改它（或用 GM 指令直接塞物品），**改完必须重启服务端**才生效。
- 想在游戏里找到某家店买不了/卖光了：`resetShopLimit @10001` 可以把每日/每周限购次数重置。
- 商店是进程启动时一次性构建的，重启后 `Shop data successfully loaded.` 就说明灌进去了。
### 关于文件里的注释

`Banners.json` 和 `Shop.json` 里现在每行后面都带 `//` 注释，服务端用的 JSON 解析器（Gson 宽模式）**是接受 `//` 注释的**，我带着注释真启动过一次服务端，没有报 `Unable to load banners` / `Unable to load shop data`，说明注释不影响加载。

- 改数值时**注释可以留着**，逗号位置别动就行。
- 真要手工核对格式，把注释当成不存在：`{ "a": 1, // 注释` 去掉注释后必须还是合法 JSON（最后一项后面不能多逗号）。
- 万一改坏了：`脚本\_备份与排障\Banners.json.bak_nocomment`、`脚本\_备份与排障\Shop.json.bak_nocomment` 是这两个文件加注释之前那份纯 JSON，直接复制回去即可。
