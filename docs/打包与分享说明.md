# 打包与分享说明（这份是给你自己看的）

目标：把 `C:\XH_YS` 压成一个包发给朋友，他**解压 → 双击一次 → 就能玩**。

---

## 一、压缩之前先在本机跑一遍自检

双击 `教程\自检.bat`，确认是「环境自检通过」。这样能保证你压出去的包里没有缺文件、补丁齐全、启动器配置模板也正常。

---

## 二、怎么压

推荐 **7-Zip**（免费，处理 66GB 最稳）：

1. 右键 `XH_YS` 文件夹 → `7-Zip` → `添加到压缩包...`
2. 压缩格式 `7z`，压缩等级选 **仅存储**（Store）
   - 客户端 66GB 主要是音频/贴图/资源包，**几乎压不动**，用普通压缩要多花几倍时间、体积只小一点点；存储模式几分钟就能出包，最终约 70GB。
3. 勾上「包含隐藏文件 / 系统文件」——`游戏\` 里有 `HoYoKProtect.sys`、`mhyprot3.Sys` 这类隐藏文件，漏了客户端可能起不来。
4. 要传网盘而单文件有上限，就设 **分卷 4096MB**，让朋友把所有分卷放在同一目录里解压。

切忌用 Windows 资源管理器自带的「压缩文件夹」——对超过 4GB 的单文件不可靠（客户端里 `GenshinImpact_Data` 就有大文件）。

---

## 三、这个包里有什么 / 没什么

| 有 | 说明 |
| --- | --- |
| `游戏\` | 客户端本体，必带 |
| `配置\服务端` `配置\数据库` `配置\工具` | 服务端、MongoDB、启动器、补丁母本，必带 |
| `脚本\` | 一键启动/关闭、指令工具、完整说明.md |
| `教程\` | 部署教程、一键部署.bat、自检.bat |
| `配置\数据库\data` | **你的存档**（UID 10001、角色、进度） |

| 没有 | 原因 |
| --- | --- |
| Java 17 | 有 Oracle 授权问题，不能打包分发；朋友的「一键部署.bat」会自动下载开源版 Temurin 17，或提示他手动装。 |
| 你这台机器的启动器配置（`%APPDATA%\cultivation`） | 部署脚本会按朋友的路径重新生成，带上反而会路径错乱。 |
| 证书文件 | 启动器在朋友机器上自己生成并安装，不需要你的私钥。 |

---

## 四、想给朋友一个「全新存档」

`配置\数据库\data` 就是存档库。想让他从零开始（自己建号、自己抽卡）：

1. 先双击 `脚本\关闭游戏.bat` 关服（一定要关，不然数据文件被占用）
2. 清空 `配置\数据库\data` 里的内容（只删里面的东西，`data` 文件夹本身留着）
3. 再打包

服务端下次启动会自动重建库结构，不影响运行。**清空前想留底就先整个复制一份 `data` 出来。**

---

## 五、告诉朋友的最低要求（可以直接转发这三句）

1. Windows 10/11 64 位，内存 8GB 以上，留出约 70GB 硬盘。
2. 解压到短路径（如 `D:\XH_YS`），别放 Program Files / OneDrive / 桌面深处。
3. 双击 `教程\一键部署.bat`，按提示走完，最后问「现在直接开服？」输 Y；以后每次玩只要双击 `脚本\开始游戏.bat`。

登录账号 `test` / `123456`（随便填也会自动建号），UID 10001，延迟个位数毫秒。

---

## 六、几个注意事项

- **别改四个文件夹的名字**（`游戏` / `配置` / `脚本` / `教程`），脚本靠相对路径找文件，改名就全乱；整个 `XH_YS` 目录本身改名或换盘（C: → D:）是可以的。
- 别放在 OneDrive、坚果云、百度网盘同步目录里打包/解压，同步进程会锁文件导致服务端起不来。
- 朋友那边如果杀软把 `mongod.exe`、`version.dll` 当病毒删了，让他把整个文件夹加白名单，再跑一次「一键部署.bat」。
- 传输用了分卷的话，务必提醒朋友**全部分卷下齐再解压**，缺一卷会解压失败。
- 想省事也可以压成 `.7z` 后放网盘分享链接；70GB 上传一次挺费时间，建议局域网直接拷贝移动硬盘。
