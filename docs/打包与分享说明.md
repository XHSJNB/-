# 打包与分享说明（维护者看这份）

## 结论：不要再打 70GB 整合包

- 客户端 66GB 是米哈游官方资源，转存/公开分发既慢又有版权风险，**直接给官方 CDN 链接**
- GitHub 单文件 100MB、Release 单资产 2GB，70GB 至少要切 35 个分卷
- 网盘的「免登录直链」基本都收口了（123 云盘直链已绑付费流量包、百度非会员限速、阿里/夸克要登录+客户端）

## 现在的分发结构

| 东西 | 走哪 | 为什么 |
| --- | --- | --- |
| 游戏客户端 4.0.0 + 中文语音 | 官方 CDN 直链（写进 README/教程） | 满速、可续传、不占仓库体积 |
| Java 17 / MongoDB / Grasscutter jar / resources / opencommand | 官方链接，由 `教程\组装.ps1` 自动下载 | 都是稳定官方地址，没必要再托管一份 |
| 脚本 / 调好的 `config.json` / 客户端补丁 `version.dll` / 便携启动器 / GcTools | **`XH_YS_Kit.7z`**（Release 附件，14MB） | 没有现成链接，或官方只发 msi 需要管理员 |

## 重新打 Kit（改完脚本/配置后）

```powershell
cd C:\XH_YS
& 'D:\Program Files\7-Zip\7z.exe' a -t7z -mx=5 -mmt=on D:\XH_YS_Server\XH_YS_Kit.7z `
    配置\工具 配置\服务端\config.json 配置\服务端\plugins 配置\服务端\data `
    脚本\开始游戏.bat 脚本\关闭游戏.bat 脚本\指令工具.bat `
    脚本\start_all.ps1 脚本\stop_all.ps1 脚本\run_mongo.cmd 脚本\run_server.cmd 脚本\说明.md `
    教程
```

注意：

- 别把 `配置\数据库\` 打进去（MongoDB 有官方 zip，且 `.pdb` 调试符号就有 1.5GB）
- 别把 `配置\服务端\resources`、`*.jar` 打进去（都有官方链接）
- `.ps1` 必须存成 **UTF-8 带 BOM**，否则别人机器上中文会乱码
- 打完 `7z t` 测一遍，把大小和 SHA256 写进 Release 说明

## 发布到 Release

1. Release 用 tag `v1.0`（升级兼容包时改 tag，如 `v1.1`）
2. 附件只放 `XH_YS_Kit.7z`，单资产远小于 2GB，秒传
3. Release 说明里贴：Kit 的大小/SHA256、用法四步、各组件官方链接表
4. 改完 README / 教程后同步到 `docs/`、`setup/`、`scripts/`，再 `git push`

## 给朋友的话术

> 装这套不用网盘：客户端从官方地址下，其他组件脚本会自动下，只有 14MB 的脚本包在 GitHub Release。
