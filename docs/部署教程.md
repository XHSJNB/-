# 原神 4.0 私服 · 部署教程（收包的人看这份）

整套东西解压就能跑，**不需要安装 MongoDB、不需要改 hosts、不需要手动填启动器路径**。
流程只有三步：**解压 → 双击一次「一键部署.bat」→ 按提示进游戏**。

---

## 一、先确认你的电脑够用

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，**64 位** |
| 内存 | 8GB 以上（服务端会占 2~6GB） |
| 硬盘 | 解压后需要约 **70GB** 空间（客户端本体 66GB） |
| 网络 | 只有「没装 Java 17」时才需要联网一次自动下载 |
| 权限 | 普通用户就行，不用管理员 |

> 不要装到 `C:\Program Files`、桌面深处、OneDrive / 坚果云同步目录里，容易权限或同步问题。

---

## 二、解压

1. 用 **7-Zip / Bandizip / WinRAR** 解压（Windows 自带的 zip 对 4GB 以上文件不靠谱）。
   如果是分卷压缩包，把所有分卷下到**同一个文件夹**，右键第一个分卷解压即可。
2. 目标路径尽量短，推荐 **`D:\XH_YS`**。
3. 解压完打开这个文件夹，应该正好看到四个文件夹：

```
XH_YS
├─ 游戏\     客户端本体（66GB，GenshinImpact.exe 在这里）
├─ 配置\     服务端 / 数据库 / 工具 / 教程源码
├─ 脚本\     开始游戏.bat、关闭游戏.bat、指令工具.bat、说明.md
└─ 教程\     本教程 + 一键部署.bat + 自检.bat
```

四个都在，才说明解压完整。

---

## 三、双击「一键部署.bat」

进 `教程` 文件夹，双击 **`一键部署.bat`**。它会依次自动做这些事：

| 步骤 | 它做什么 | 你要做什么 |
| --- | --- | --- |
| 1 | 检查四个文件夹、客户端 exe、服务端 jar 是否齐全 | 无 |
| 2 | 找 Java 17（PATH、常见安装目录、注册表都会扫） | 找不到时问你要不要自动下载，**输 Y** 等它下完（约 190MB，1~3 分钟） |
| 3 | 校验并修复客户端补丁 `version.dll` / `PublicKey.txt` | 无 |
| 4 | 按**你这台机器的真实路径**生成启动器配置 | 无 |
| 5 | 检查 443 / 27017 端口有没有被别的程序占用 | 无（有冲突会告诉你是哪个进程） |
| 6 | 真跑一次 MongoDB 验证它能启动，然后正常关掉 | 无 |
| 7 | 检查 VC++ 运行库、长路径、系统位数 | 无 |

最后会提示「环境自检通过」，并问你 **现在直接开服并进游戏？(Y/N)** —— 输 **Y**，它会拉起数据库、服务端、启动器并自动点【启动】。

如果中途报了 `[问题]` 行，按那行提示处理，再双击一次「一键部署.bat」即可（重复跑是安全的）。

---

## 四、进游戏

1. 游戏窗口起来后，**多数情况**会直接显示「点击进入」，点一下就进服。
2. 如果弹出 **HOYOVERSE 登录框**：账号 `test`、密码 `123456`（其实随便填也行，服务端会自动建号）。
3. 进服后 UID 是 `10001`，延迟一般个位数毫秒（因为服务端就在你本机）。
4. **启动器的窗口别关** —— 它开着本地代理，关了登录会失败。

玩完双击 **`脚本\关闭游戏.bat`**，它会把游戏、启动器、系统代理、服务端、数据库依次关干净。

---

## 五、以后每次玩

不用再跑部署脚本，直接双击 **`脚本\开始游戏.bat`** 就行。

想改数值（原石、属性、卡池、商店）看 `脚本\说明.md`；图形化发 GM 指令双击 `脚本\指令工具.bat`。

---

## 六、遇到问题先跑「自检」

`教程\自检.bat` 只检查不启动，随时可以跑，会列出所有卡点。

常见问题对照：

| 现象 | 原因 / 处理 |
| --- | --- |
| 弹「网络错误 4206 / 4214 / 4210」 | 客户端缺 `version.dll` 补丁。重跑「一键部署.bat」，它会自动装回；或手动把 `配置\工具\patch_master\version.dll` 复制到 `游戏\`。 |
| 登录页「服务器繁忙 / 502」 | 启动器没在跑（没有 8365 代理），或启动器里勾了「使用 HTTPS」。重跑「开始游戏.bat」，保持启动器窗口开着。 |
| 点了【启动】只弹出资源管理器 | 启动器里游戏路径填成了目录而不是 exe。重跑「一键部署.bat」会自动改对。 |
| 启动器闪退 | 必须带 `--no-admin` 参数启动（bat 里已经带好了，别自己直接双击 exe）。 |
| 双击 bat 一闪就没了 / 服务端黑窗口报 Java 错误 | Java 17 没装好。跑「自检.bat」看第一条，按提示装或让它自动下。 |
| 黑窗口里敲命令报「`/give` 不是内部或外部命令」 | 那是上一次运行留下的死窗口，敲什么都会报错。关掉它，重跑「开始游戏.bat」。 |
| 443 端口被占用 | 自检会报是哪个进程。常见是 IIS、其它 web 服务、残留的 java；关掉它再启动。 |
| 杀毒软件报毒 / 把文件删了 | `mongod.exe`、`version.dll`（客户端补丁）容易被误报。把整个 XH_YS 文件夹加进白名单。 |
| MongoDB 起不来（日志里有 api-ms-win / vcruntime 之类） | 缺微软运行库，装 https://aka.ms/vs/17/release/vc_redist.x64.exe 后重启。 |
| 游戏闪退 / 黑屏 | 显卡驱动太旧，或没装 VC++ 运行库；笔记本切到独显再试。 |
| 玩完浏览器上不了网 | 系统代理没复位：双击 `脚本\关闭游戏.bat`，或到「设置 → 网络和 Internet → 代理」关掉「使用代理服务器」。 |
| 想彻底重来 | 关掉所有窗口，重跑「一键部署.bat」即可，它不会动你的存档。 |

## 七、安全与说明

- 服务端只监听本机 `127.0.0.1`（443 / 22102 / 8365），**不对外网开放**，局域网里别人也连不进来。
- 启动器会在「当前用户 → 受信任的根证书颁发机构」里装一张 `O=Grasscutters, CN=Cultivation` 的本地根证书（用来劫持登录请求到本地服务端）。不想要了：`certmgr.msc` → 受信任的根证书颁发机构 → 找到它删除。
- 账号/存档在 `配置\数据库\data`（拿到手的包如果带着别人的存档，UID 会是 10001；想从零开始就关服后清空这个目录）。
- 这套是**离线单机私服**，客户端是 4.0 国际版定制包，**不要用官方最新客户端覆盖**，也不要联到官方服务器。
