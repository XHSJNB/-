# 原神 4.0 私服 · 部署教程（收包的人看这份）

整套东西**不需要网盘、不需要移动硬盘、不需要谁帮你挂着做种**：

- 游戏客户端：从米哈游官方 CDN 直下（满速、可续传）
- 各个组件（Java 17 / MongoDB / 服务端 / resources / 插件）：都有官方链接，`组装.bat` 会按链接自动下
- 只有「脚本、调好的配置、客户端补丁、便携启动器」这些没现成链接的东西，在仓库 Release 的 `XH_YS_Kit.7z`（14MB）里

流程：**下 Kit → 解压 → 双击 组装.bat（缺什么下什么）→ 下客户端 → 双击 一键部署.bat → 进游戏**。

---

## 一、先确认电脑够用

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，**64 位** |
| 内存 | 8GB 以上（服务端占 2~6GB） |
| 硬盘 | 约 **70GB** 可用空间（客户端解压后 66GB） |
| 下载量 | 约 **68.5GB**（客户端 66.6GB + 组件约 1.9GB） |
| 权限 | 普通用户就行，不用管理员 |

> 不要装到 `C:\Program Files`、桌面深处、OneDrive / 坚果云同步目录。推荐 **`D:\XH_YS`**。

---

## 二、准备目录 + 装 Kit

1. 新建 **`D:\XH_YS`**，并在里面建一个 **`游戏`** 文件夹。
2. 到本仓库 **Releases → v1.0** 下载 **`XH_YS_Kit.7z`**（约 14MB）：
   <https://github.com/XHSJNB/-/releases/tag/v1.0>
3. 用 7-Zip 把它**解压到 `D:\XH_YS\`**，会得到三个文件夹：`配置\`、`脚本\`、`教程\`。

> Kit 里有：全部脚本、调好的 `config.json`、客户端补丁 `version.dll`、便携版启动器 Cultivation、GcTools 指令工具。**没有**服务端 jar、resources、MongoDB、Java——那些走官方链接自动下。

---

## 三、双击「组装.bat」——缺什么下什么

进 `教程` 文件夹，双击 **`组装.bat`**，它会：

| 步骤 | 它做什么 | 来源 |
| --- | --- | --- |
| 1 | 找 Java 17，没有就下 | Temurin 17（约 182MB） |
| 2 | 找 MongoDB，没有就下 | 7.0.5 免安装 zip（约 594MB） |
| 3 | 下服务端 jar（约 98MB） | GitHub Grasscutters/Grasscutter |
| 4 | 下 resources（约 1GB） | GitLab 官方归档 |
| 5 | 下 opencommand 插件（100KB） | GitHub |
| 6 | 检查客户端放没放齐 | 没放齐就把两条官方直链打给你 |

下载用 Windows 自带的 curl，**支持断点续传**：断了直接重跑 `组装.bat`，会接着下。
已经在的组件会自动跳过，重复跑是安全的。

到第 6 步它会告诉你客户端还缺什么，这时去下（见下一节），下完**再跑一次** `组装.bat`，看到「全部齐了」即可。

---

## 四、下载游戏客户端（官方 CDN，两段）

浏览器、IDM、迅雷都能下，**支持断点续传**。

| 内容 | 体积 | 直链 |
| --- | --- | --- |
| 游戏本体 4.0.0 | 56.16 GB | <https://autopatchhk.yuanshen.com/client_app/download/pc_zip/20230804185804_eTmE8EZjJZdAJapq/GenshinImpact_4.0.0.zip> |
| 中文语音包 | 10.45 GB | <https://autopatchhk.yuanshen.com/client_app/download/pc_zip/20230804185804_eTmE8EZjJZdAJapq/Audio_Chinese_4.0.0.zip> |

两个 zip 都解压到 **`D:\XH_YS\游戏\`**：

- 本体 zip 里没有多余一层文件夹，解压完应该直接看到 `GenshinImpact.exe` 和 `GenshinImpact_Data`
- 语音包解出来是 `GenshinImpact_Data\StreamingAssets\AudioAssets\Chinese\*.pck`，同名文件夹选「合并 / 覆盖」

---

## 五、双击「一键部署.bat」

再进 `教程`，双击 **`一键部署.bat`**：

| 步骤 | 它做什么 | 你要做什么 |
| --- | --- | --- |
| 1 | 检查四个文件夹、`GenshinImpact.exe`、服务端 jar 是否齐全 | 无 |
| 2 | 复核 Java 17 并写进 `配置\java_path.txt` | 无（缺了会问你要不要自动下） |
| 3 | 校验并修复客户端补丁 `version.dll` / `PublicKey.txt` | 无 |
| 4 | 按你这台机器的真实路径生成启动器配置 | 无 |
| 5 | 检查 443 / 27017 端口有没有被占用 | 无（冲突会说是哪个进程） |
| 6 | 真跑一次 MongoDB 验证能启动，再正常关掉 | 无 |
| 7 | 检查 VC++ 运行库、长路径、系统位数 | 无 |

最后问 **现在直接开服并进游戏？(Y/N)** —— 输 **Y**，它会拉起数据库、服务端、启动器并自动点【启动】。

中途报 `[问题]` 就按那行处理，再双击一次（重复跑安全）。

---

## 六、进游戏

1. 游戏窗口起来后，多数情况直接显示「点击进入」，点一下进服。
2. 弹 HOYOVERSE 登录框时：账号 `test`、密码 `123456`（随便填也行，会自动建号）。
3. 进服后 UID `10001`，延迟个位数毫秒。
4. **启动器窗口别关**，它开着本地代理，关了登录会失败。

玩完双击 **`脚本\关闭游戏.bat`**，游戏、启动器、系统代理、服务端、数据库依次关干净。

---

## 七、以后每次玩

直接双击 **`脚本\开始游戏.bat`**。想改数值看 `脚本\说明.md`；图形化发指令双击 `脚本\指令工具.bat`。

---

## 八、遇到问题

`教程\自检.bat` 只检查不启动，随时可跑。

| 现象 | 原因 / 处理 |
| --- | --- |
| resources 下载很慢 / 断了 | GitLab 国内不稳。重跑 `组装.bat` 续传；或手动下 <https://gitlab.com/api/v4/projects/35984297/repository/archive.zip>，解出 `resources` 放到 `配置\服务端\` |
| 弹「网络错误 4206 / 4214 / 4210」 | 客户端缺 `version.dll` 补丁。重跑「一键部署.bat」，或把 `配置\工具\patch_master\version.dll` 复制到 `游戏\` |
| 登录页「服务器繁忙 / 502」 | 启动器没在跑，或勾了「使用 HTTPS」。重跑「开始游戏.bat」，启动器别关 |
| 点【启动】只弹资源管理器 | 启动器里游戏路径填成了目录。重跑「一键部署.bat」会自动改对 |
| 启动器闪退 | 必须用 Kit 里的便携版（bat 已带 `--no-admin`），别用官方 msi 装的那个 |
| 双击 bat 一闪就没 / 服务端报 Java 错误 | Java 17 没装好。跑「组装.bat」或「自检.bat」 |
| 443 端口被占用 | 自检会报占用进程，常见 IIS、其它 web 服务、残留 java |
| 杀毒软件报毒 | `mongod.exe`、`version.dll` 易被误报，把整个 XH_YS 加白名单 |
| MongoDB 起不来（vcruntime 之类） | 装 <https://aka.ms/vs/17/release/vc_redist.x64.exe> 后重启 |
| 客户端解压报「文件损坏」 | 56GB 包下断了，用 IDM / 迅雷重下 |
| 玩完浏览器上不了网 | 双击 `脚本\关闭游戏.bat` 复位代理 |
| 想彻底重来 | 关掉所有窗口重跑「一键部署.bat」，不会动存档 |

## 九、安全与说明

- 服务端只监听本机 `127.0.0.1`（443 / 22102 / 8365），**不对外网开放**。
- 启动器会装一张 `O=Grasscutters, CN=Cultivation` 的本地根证书（劫持登录请求到本地服务端）。不想要了：`certmgr.msc` → 受信任的根证书颁发机构 → 删除。
- 存档在 `配置\数据库\data`，Kit 交付时是空的，首次登录自动建号；想彻底重开就关服清空。
- 客户端是米哈游官方安装包，**不要用官方最新客户端覆盖**，也不要联到官方服务器。
- 本仓库不托管任何游戏资源，全部组件由使用者从官方公开地址获取。
